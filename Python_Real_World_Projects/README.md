# Python in the Real World — 30 Projects

This folder contains one starter Python file for each workbook challenge.

## How to use
1. Open this folder in VS Code.
2. Work through the numbered folders in order.
3. Write each solution in its matching `.py` file.
4. Run a file in the terminal with `python filename.py`.
5. Test the workbook example and at least two additional cases.

The Python files are starter files; we'll add solutions as we complete each challenge.
