# Python in the Real World - Solutions

30 scenario-based solutions, one folder per topic.

Run one program:  `python 02_Functions/payroll.py`
Run everything:   `python run_all.py`

Each file contains the solution, the workbook example (checked with `assert`),
extra test cases, and input validation. Programs in `03_Conditionals` also
offer a live input prompt at the end.

Notes on interpretation
- Challenge 01: "average per item" follows the workbook example (gross sales / items = 29923.08).
- Challenge 14: `book_seat` returns `(message, available_seats_tuple)` so both requirements are met.
- Challenge 15: an empty list raises a clear `ValueError`.
